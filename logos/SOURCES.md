# Logo sources

Each logo in the first table is the vendor's own file, taken from the vendor's repository or
website on 2026-10-10 and left unchanged (only LibreWolf's editor metadata was removed). The four
in the second table come from public icon sets, because the vendors' files were not reachable
when the logos were collected. All of them are trademarks of their owners and are only used to
identify the apps in Agent Center. Agent Center is not affiliated with any of these vendors.

Agent Center draws each logo on a white rounded tile (black for T3 Code, whose app icon puts the
mark on black), so dark and light marks both read in any theme.
